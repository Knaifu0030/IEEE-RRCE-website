# Documentation

Start with `STRUCTURE.md` if this is your first time in the project.

| File | What it covers |
|---|---|
| `STRUCTURE.md` | Every file and folder in the project, and when you would open each one. |
| `DESIGN-SYSTEM.md` | Colours, fonts, spacing, the shape rule, and the reusable CSS classes. |
| `HOW-TO.md` | Step-by-step recipes: run the site, add an event, change the live date, add a page, swap an image, connect the forms. |
| `ACCESSIBILITY.md` | What the site does for keyboard, screen-reader and reduced-motion users, and how to keep it working. |
| `CONTENT-SOURCES.md` | Where every name, date and number on the site came from. |

The site needs no build tools. Open `../index.html` in a browser and it runs.
